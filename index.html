JSON → Barcodes

Paste JSON or choose a file, then Generate barcodes. NSAP payloads use ShipmentNumber once, then DeliveryNumber per delivery, then per ShipmentDeliveryItemId (fallback LineNumber): seals, batch (hidden when ContainerType is BULK), storage, GTIN, EANNumber, YSLDPackageCode, ProductNumber, and slash composites EquipmentNumber/ProductNumber, …/EANNumber, …/GTIN, …/FormulaCode, …/YSLDPackageCode (both sides non-empty). Any other JSON is scanned for primitives (depth limit).
